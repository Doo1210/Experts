# 专家对话演示触发语

本文记录**当前前端本地模拟器**的触发方式，依据 `src/demo/state.js` 中的 `sendDemoMessage()`。在专家对话页发送示例文字即可查看对应呈现。它们是演示脚本关键词，不代表真实模型会按这些文字执行任务，也不属于产品 PRD 的功能规则。

关键词场景的处理过程现在至少持续约 6 秒，以便观察流式文字、活动与进度变化；中途说明等额外阶段可能使总时长更长。普通输入仍较快完成，人工请求出现后会一直等待用户操作。

质量分析专家的任务列表中内置「多问题定位演示（72问）」会话，可直接查看问题定位条在问题较多时的独立滚动、逐项预览和点击定位；该会话由本地样例生成，不依赖输入触发语。

## 1. 基础回复与正文

- `你好`：普通流式答复，不产生工具或人工请求。
- `演示过程`：先展示中途说明，再展示活动组和最终答复。单独使用 `中途` 也会触发中途说明，但不会自动触发工具。
- `Markdown 展示`：展示标题、表格、本地图片、强调、代码块和链接。
- 上传文件并发送：右侧用户消息展示本地附件引用；纯附件发送不重复显示文件名正文。这是文件操作，不靠特定文字触发。

## 2. 过程活动与工具

- `核对资料`、`查看工作目录`、`处理文件`、`使用工具`：触发普通工具活动。只要文字中包含 `资料`、`工作目录`、`文件` 或 `工具` 就会命中。
- `查看进度`：模拟网页提取工具的可读进度，并在原活动中更新。
- `工具详情`：模拟命令工具，在展开活动中查看安全入参与可读输出。
- `文件差异`：模拟补丁工具，在展开活动中查看固定差异；不会修改真实文件。
- `并行工具`：两个工具并行开始并分别结算。
- `并行过程`：并行工具之外还会出现中途说明。
- `请展示思考`：显示一项可见的“思考”活动，片段会合并到同一项。
- `请使用并行模型`：显示一项并行模型活动及参考意见，不生成多份最终答复。
- `请用子代理分析资料`：显示子代理活动；其中 `资料` 还会触发工具。
- `后台子代理核对资料`：父回合答复后，子代理再更新原活动。
- `请等待`：短暂显示等待提示；正文开始后提示即消失，回合历史不会保留等待动画。

## 3. 人工介入

下面的请求在模拟文字输出后出现。请通过输入区上方的操作区作答，不要另发一条普通消息。

- `请澄清`：单题自由输入澄清。
- `请多题澄清`：两道问题，分别演示单选与多选。
- `已答多题澄清`：其中一道题预置为“已接收”，只需回答剩余题目。
- `请审批`：允许或拒绝本次演示操作。允许后会出现独立的后续工具活动。
- `请审批后演示失败`：允许操作后，后续工具失败；用来查看“批准”与“执行结果”分开呈现。拒绝则直接中断本轮。
- `MCP 设置确认`：模拟配置决定及之后的示例 MCP 检查活动。
- `凭据演示`：只显示模拟安全提交与取消，不收集真实密钥。
- `管理员密码演示`：同样只模拟安全提交状态，不收集真实密码。

## 4. 当前会话状态与本轮结果

- `列出待办`：建立当前会话待办快照，显示在输入区上方。
- `层级待办`：**当前会话还没有待办时**建立父子层级及取消项；已有待办时会沿用并更新现有快照。要重看初始层级场景，可新建任务或重置演示数据。
- `完成待办`：把当前待办列表的第一项标为已完成。
- `生成待办结果`：更新当前待办，并在本轮最终答复后保存一份本轮清单快照；之后的待办更新不改动旧回合结果。
- `设置目标`：显示当前会话目标及轮次预算。
- `目标等待`：显示目标和演示等待条件。
- `演示排队任务`：建立三条按顺序等待执行的本地队列快照；展开队列后可分别查看每条任务内容。
- `清空排队任务`：清除当前会话的本地队列快照。
- `设置循环`、`查看心跳`：分别显示循环与心跳状态；可和目标、待办同时存在。
- `引用资料`：如当前专家有内置的可引用文件，则在本轮结果中显示关联文件。
- `账户通知`：显示页面级演示额度提醒，不插入助手答复。
- `清除账户通知`：清除上述页面提醒。

## 5. 异常

- `演示失败` 或 `演示错误`：触发工具失败与回合失败，已生成的正文仍保留，异常原因独立显示在回合末尾。
- `请审批后演示失败`：特意用于验证授权成功不等于后续执行成功。

## 6. 组合、优先级与限制

- 触发逻辑采用**包含关键词**，不是精确匹配。例如“分析审批失败原因”也会命中审批和失败场景。这是当前演示脚本的限制，不能将结果理解成专家对原文的真实判断。
- 文字可组合，例如 `层级待办和目标等待` 同时更新待办与目标；`并行过程` 同时触发并行工具与中途说明。
- 同时包含多个人工介入词时，只选一种，优先级为：`凭据演示` → `管理员密码演示` → `MCP 设置确认` → `审批` → `澄清`。
- 同时包含多个特殊活动词时，只选一种，优先级为：`子代理` → `并行模型` → `思考`。
- 工具类型优先级为：包含 `进度` 时用网页提取；否则 `工具详情` 用命令；否则 `文件差异` 用补丁；否则使用普通读取活动。因此不要把这些词放在同一条测试语里。
- 人工请求回复优先于普通答复；无人工请求时，`失败/错误` 优先于 `Markdown 展示` 和 `文件差异` 的固定答复。`生成待办结果` 和 `引用资料` 在失败或人工请求回合中不会生成本轮结果。
- 当前所有事件、文件和状态仅保存在浏览器本地；切换或离开任务会停止该任务尚未完成的模拟流。
