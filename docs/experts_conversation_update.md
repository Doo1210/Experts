# 专家对话页变更记录

## 2026-11-19

### 预览区：路径与操作栏

- 标签页与正文之间增加 36px 高的路径及操作栏；路径使用椭圆胶囊，开头固定显示来源图标，与文档标签保持一致。路径始终单行，过长时省略前段目录，知识文档与 Wiki 路径以实际知识库名称开头；右侧固定预留两个操作图标的位置。
- 按来源分别提供工作空间新网页查看、知识文档引用定位及新网页查看、Wiki 图谱查看。知识文档展示全文，引用切换改为同一文档内定位与高亮。详细规则见 [4.5](#45-路径与操作栏)。

### 预览区：默认宽度

- 默认宽度为 **480px**；手动调整后在本页保留所选宽度，并遵守当前可用空间及最小宽度边界。

### 检索知识：完成节点与需求归档

- 「完成检索」节点仅保留完成图标、标题和「共返回……」数量统计，移除「已查到……」等总结文字及其展开／收起按钮。统计仍为不可点击的普通文字。
- 第三章新增 [3.6 检索知识](#36-检索知识)，统一记录检索范围、活动归属、过程时间线、完成统计、正文引用、阅读内容及验收要求；引用阅读沿用 [3.5](#35-知识引用直接阅读) 和第四章的统一预览区规则。

### 对话区、预览区与工作空间：关闭预览后的宽度分配

- 修复关闭整个预览区或最后一个文件标签后，工作空间向左偏移、页面右侧留下空白的问题。
- 预览区隐藏后重新计算布局宽度，对话区填满全部释放的空间；已展开的工作空间始终贴齐主面板右边缘。
- 关闭时保留任务列表和工作空间的当前显隐状态及已调整宽度；关闭非最后一个标签时保持区域布局。任务列表收起及窄窗口下遵循相同规则。

## 2026-11-18

本文用于研发核对当日需求变更，按最终确认方案整理。涉及 Banner、任务列表、对话区、预览区、工作空间五个区域。

页面从左到右为：**任务列表 → 对话区 → 预览区 → 工作空间**。预览区有文件时显示；打开对话区的知识引用或文件卡片时，工作空间保持当前显隐状态。

整体采用浅中性灰与白色，蓝色用于主操作、选中状态及引用提示。圆角主面板外侧背景为 **`#F8F8F8`**，区域分隔线统一为 **`#E8E8E8`**；各区域的具体样式见下文。

### 1. Banner

- 移除页面顶部的「任务列表」按钮和「新建任务」按钮，保留返回、专家头像与名称，以及独立的「工作空间」显示／隐藏按钮。
- 返回按钮进入专家列表；专家头像与名称作为整体可点击区域，进入当前专家管理页，悬停提示「打开专家管理页」。
- 加强管理页入口的悬停反馈：底色为 **`#E8E8E8`**，边框为 **`#DEDEDE`**。键盘聚焦提供同样反馈，悬停、移出及聚焦时保持入口位置和尺寸稳定。
- 顶部 Banner 背景为极浅灰色 **`#FAFAFA`**。
- 任务列表顶部、工作空间顶部、预览区文件标签栏的高度统一为 **40px**，三者保持对齐。

### 2. 任务列表

#### 2.1 布局与收起／展开

- 任务列表从右侧移到页面左侧，默认展开，默认宽度为 **160px**。不同文件预览场景共用同一任务侧栏，不改变其位置或形态。
- 支持拖动右边缘调整宽度；收起、展开及切换任务后，在可用空间内保留本页调整的宽度，边界规则见 3.1。
- 顶部去掉「任务列表」文字及图标，改为左侧收起图标按钮、右侧长方形「新建任务」按钮。新建任务按钮使用蓝色实心方框，尽量填满收起按钮右侧的剩余宽度，并随任务列表宽度变化。
- 收起及新建任务按钮使用小尺寸，顶部按钮区不设置独立白色底板，与下方任务列表背景融合。
- 收起后隐藏任务侧栏，在对话区左侧留白、问题定位条上方竖排悬浮显示两个小方形按钮：上方展开、下方新建任务。按钮不参与对话区布局，不占用对话展示区的高度或宽度；新建任务保留蓝色实心方框，两个按钮均提供操作提示。
- 展开与收起共用同一个按钮，位置和尺寸保持一致，仅切换图标。

#### 2.2 卡片工作目录

- 工作目录入口显示「文件夹图标＋末级目录名」，卡片内不显示「工作目录」文字标签和右侧 `>`。
- 名称超长时省略；悬停提示格式为「工作目录：完整路径」，路径从 `workspace` 开始，例如 `工作目录：workspace/分析资料/季度复盘`。根目录名称为 `workspace`，提示为 `工作目录：workspace`。
- 点击图标或目录名仍打开工作空间并定位到对应目录。
- 文件夹图标与右侧操作图标保持视觉大小一致，并与第二行的归档、删除图标在同一水平线上。

#### 2.3 卡片操作与样式

- 四个操作按钮按 **2×2 排列**：

  | 行     | 左侧     | 右侧           |
  | ------ | -------- | -------------- |
  | 第一行 | 编辑名称 | 置顶／取消置顶 |
  | 第二行 | 归档     | 删除           |

- 操作区在鼠标悬停或键盘聚焦时显示，点击操作不触发任务切换。
- 图标统一为圆角线条风格，按实际轮廓校准视觉大小；卡片、按钮间距及四周留白采用紧凑布局。
- 操作区紧贴卡片右侧悬浮展示，不额外占用布局宽度，悬停前后任务名称和目录行的布局宽度保持一致。
- 操作区左缘使用窄幅、轻度毛玻璃渐隐：向左扩散范围为 **4px**，模糊为 **2px**，尽量多显示左侧任务名称。
- 置顶使用经典斜向图钉。常驻图标与操作态使用相同轮廓、线宽、尺寸和位置，切换时不偏移；悬停时常驻图标保持到操作区出现，避免短暂消失。
- 长任务名称保留完整名称提示。
- 任务列表背景为极浅灰色 **`#FAFAFA`**；未选中任务项使用透明底色及透明边框，弱化独立白色卡片感。
- 悬停或键盘聚焦任务项时，显示浅灰底色 **`#F2F2F2`** 和细边框；选中项使用 **`#E8F0FF`** 浅蓝底色，并保留蓝色文字及左侧标识。

### 3. 对话区

#### 3.1 布局与区域宽度联动

- 对话区位于任务列表和预览区之间，填满页面剩余空间，背景为**纯白色 `#FFFFFF`**。
- 对话正文默认字号为 **14px**，包括用户消息和助手回复；行内代码及代码块字号为 **12px**。
- 工作空间及预览区均未打开时，收起任务列表后，消息内容和输入区保持居中。
- 四个区域的宽度参数如下：

  | 区域     | 默认宽度     | 最小宽度 | 最大宽度                    | 调整入口       |
  | -------- | ------------ | -------- | --------------------------- | -------------- |
  | 任务列表 | 160px        | 160px    | 480px，且不超过当前可用上限 | 右侧分隔线     |
  | 对话区   | 填满剩余空间 | 320px    | 当前剩余可用宽度            | 随其他区域调整 |
  | 预览区   | 480px        | 260px    | 当前可用上限                | 左侧分隔线     |
  | 工作空间 | 200px        | 160px    | 480px，且不超过当前可用上限 | 左侧分隔线     |

- 任务列表、预览区、工作空间的当前可用上限为：**容器宽度 − 对话区最小宽度 320px − 其他已展开侧区域的实际宽度**。计算时不包含正在调整的区域自身。
- 三个侧区域的分隔线支持拖动，以及方向键、Home／End 调整；键盘操作使用实时宽度边界。
- 调宽、收起或展开某一区域时，仅调整该区域和对话区，其他已展开区域保持宽度。收窄或收起释放的空间交给对话区；拉宽或展开从对话区借用空间。对话区达到 **320px** 后，不能继续被压缩，须先收窄或收起其他区域。
- 展开时优先使用本页记忆宽度，超出可用空间则缩至可容纳宽度；若连最小宽度也无法容纳，保持原布局，提示「空间不足，请先收窄或收起其他区域」。打开预览前先检查完整布局，失败时不增加标签、不改变当前侧栏状态。
- 宿主窗口缩小时，可回收各区域超过最小值的宽度；若连所有可见区域的最小宽度之和也无法容纳，保留最小宽度并允许外层横向浏览。用户拖动、展开区域不能将工作空间挤出页面。

#### 3.2 窄输入区的模型与工作目录入口

- 输入工具栏可用宽度不足时，模型选择和工作目录选择同时改为仅显示图标，隐藏具体名称及下拉箭头；拉宽后恢复文字。悬停仍显示完整信息，原选择浮层及禁用规则保持一致。
- 模型入口使用**大脑图标**，工作目录入口使用**文件夹图标**。
- 工作目录入口的悬停提示格式为「工作目录：完整路径」，路径从 `workspace` 开始，例如 `工作目录：workspace/分析资料/季度复盘`；根目录提示为 `工作目录：workspace`。文字与仅图标两种显示形态使用相同提示，与任务卡片保持一致。
- 根据工具栏实际可用宽度及当前名称长度判断，不仅依赖窗口宽度；侧栏调宽、窗口变化或名称变化后重新判断，避免文字溢出或与发送按钮重叠。

#### 3.3 修改文件差异预览入口

悬停本轮产出的修改文件卡片时，在差异预览浮窗的标题栏提供「查看全部修改」，方便查看本轮完整改动。

| 项目     | 需求                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 入口位置 | 放在差异预览浮窗标题栏内，位于增删行数（如 `+1 −1`）的左侧，与文件路径、增删行数垂直居中对齐。                           |
| 文字样式 | 文案为「查看全部修改」，字号为 11px，使用蓝色文字。                                                                      |
| 展示条件 | 文件具有可信的本轮差异时提供入口，短差异和长差异均可点击查看。                                                           |
| 点击行为 | 打开「本轮改动」浮窗，展示该回合已有的全部可展示差异。浮窗有最大高度限制，长内容在窗内滚动，继续遵守来源截断和脱敏规则。 |
| 关闭行为 | 关闭完整差异浮窗后，焦点回到对应文件卡片。                                                                               |
| 窄屏适配 | 保持入口与增删行数在同一标题行，空间不足时省略文件路径，保留入口和增删行数。                                             |

**验收方式**

发送 `演示产出：修改文件`，等待本轮产出出现后悬停文件卡片。确认「查看全部修改」以 11px 字号显示在增删行数左侧，点击可打开完整差异浮窗；长差异可在窗内滚动，关闭后焦点回到对应文件卡片。桌面与窄屏均检查标题栏的对齐和文字展示。

#### 3.4 处理摘要、活动组与活动详情

- 「处理经过」「正在推进」摘要行保持无背景填充，折叠、展开及悬停时均不显示灰色底板。
- **同一活动组展开后的所有活动行，共用一整块 `#FAFAFA` 浅灰圆角背景。** 灰底设置在活动列表外层，单个活动行保持透明，不按行拆成多个灰色圆角块；不同活动组分别成块。
- 组内活动行之间保留 4px 间隔，间隔处继续显示同一块灰底。摘要行位于灰色区域之外。
- 活动详情使用白色背景框，展开后完整嵌在该活动组的浅灰区域内；左右外边距一致，不得贴住右边缘。普通活动详情左右各留 **14px**，后台进程详情左右各留 **3px**。
- 活动组及单项详情支持独立展开／收起，运行中保留文字扫光效果。

#### 3.5 知识引用直接阅读

- 移除旧的「本轮引用知识」文字及点击入口。在「完成检索」下仅显示普通文字统计，例如「共返回 6 个文档片段、1 个 Wiki 页面、1 项计算结果」，不显示「已查到……」等总结或总结展开按钮。数量根据当前检索返回的可用结果去重计算，包含未被正文引用的结果；三类数量均展示，未返回的类别显示 0。统计文字不可点击，不使用链接样式、悬停高亮或弹窗。检索过程与统计规则见 [3.6](#36-检索知识)。
- 移除「本轮引用知识」来源浮窗、引用内容悬停弹窗，以及预览区内的引用知识卡片列表和筛选项。
- 点击对话正文中的某个具体知识引用，直接打开预览区并显示该引用关联的内容：文档引用展示全文并定位、高亮当前引用片段，Wiki 引用展示完整 Wiki 正文，计算引用展示对应计算摘要。
- 同一处引用包含多个编号时，仅高亮这些编号中属于所点击来源的片段；全文保留该文档的其他内容。Wiki 正文保留标题、段落、表格等排版；来源不可访问或正文缺失时显示相应提示。
- 引用内容使用现有文件标签：标签显示来源名称，正文区直接阅读内容，不再经过来源卡片或「查看」中间入口。同一文档的不同引用片段共用一个标签，跨回合引用同一文档也复用；点击引用时激活该文档标签，在同一全文内切换引用高亮并定位到对应片段。普通切换标签继续保留当前片段的阅读位置；不同文档按稳定标识区分，同名不能合并，缺少文档标识时不按名称猜测归属。内容更新后重新点击可刷新对应标签。
- 知识预览沿用区域宽度、工作空间显隐、关闭时保持侧栏状态及逐标签阅读位置规则。

#### 3.6 检索知识

本节记录对话区使用知识中心资料时的完整展示要求，覆盖文档片段检索、文档阅读、Wiki 检索与阅读、表格分析。过程记录与最终回复中的引用分别展示，并关联到各自所属的知识调用及回答。

##### 3.6.1 触发范围与活动归属

- 用户在输入区通过 `@` 从知识中心引用知识库或文档，发送问题后按本轮资料范围执行检索。引用知识库时在所选库内检索；引用指定文档时限定到所选文档。同轮多选合并范围，重叠资料去重。
- 未临时指定资料时，依据专家配置的有效知识范围执行。知识中心资料、工作空间文件和上传附件保留各自身份，不按名称混为同一种知识来源。
- 一次实际知识调用对应一条「检索知识」活动，以 `message_id + knowledge_run_id` 关联。调用内部的检索片段、阅读文档、查询 Wiki、阅读 Wiki 和表格分析均归入该活动，同轮多次知识调用按开始顺序各占一条活动。
- Hermes 独立执行的 `read_file` 仍作为「读取文件」活动，不并入知识内部的阅读步骤。没有实际知识调用时，不生成知识活动。

##### 3.6.2 活动行与活动组

- 检索执行中纳入「正在推进」，活动行随实际阶段更新，例如「检索知识 · 理解问题」「检索知识 · 检索片段」「检索知识 · 阅读文档」「检索知识 · 检索 Wiki」「检索知识 · 阅读 Wiki」「检索知识 · 分析表格」「检索知识 · 整理结果」。
- 知识执行已结束但结果仍在读取时，显示「检索知识 · 正在读取结果」。正常完成后活动行显示「检索知识」。组内活动全部收口后，组标题显示「处理经过：检索知识」；与其他活动同组时按实际活动概括。
- 进行中的活动使用文字扫光，有过程记录、结果或可读异常原因时显示展开入口；运行中即可展开，不必等待最终回复完成。
- 阶段按实际事件出现，允许跳过、重复和再次执行。部分完成、无结果、失败、取消、超时在活动行分别显示「部分完成」「未找到可用资料」「检索失败」「已取消」「检索超时」。
- 活动组和详情遵守 3.4 的背景、间距及独立展开规则。用户停在对话底部时跟随新内容；向上阅读历史时保留阅读位置。

##### 3.6.3 活动详情与过程记录

过程按实际发生顺序追加，采用「动作＋args」，左侧用动作小图标及浅灰竖线连接。步骤开始后先显示动作和参数；结果返回后，在该步下方补充小号灰色结果文字。当前执行步骤不附加「正在读取」「进行中」等重复状态。

| 动作      | 对应工具或事件                                          | args 展示          | 结果小字示例                                        |
| --------- | ------------------------------------------------------- | ------------------ | --------------------------------------------------- |
| 理解问题  | `query_understand`                                      | 实际问题内容       | 已完成问题理解                                      |
| 检索片段  | `search_knowledge`；普通问答进度事件 `knowledge_search` | 实际查询内容       | 命中 6 个片段，来自 3 份文档；或检索到 6 条相关内容 |
| 阅读文档  | `read_document`                                         | 带后缀的文件名     | 已读取 3 个片段                                     |
| 检索 Wiki | `wiki_search`                                           | 实际查询内容       | 找到 1 个 Wiki 页面                                 |
| 阅读 Wiki | `wiki_read_page`                                        | Wiki 页面名称      | 已读取页面；或已读取 2 个页面                       |
| 分析表格  | `data_analysis`                                         | 带后缀的表格文件名 | 已完成分析，返回 4 条结果                           |

- 所有查询统一放在一对「」内，真实的多项查询以全角 `｜` 分隔，例如「校准记录 ｜ 复核要求」。单个查询可以是完整问题或正则表达式，不自行按空格或 `|` 拆词。超长查询省略显示，保留首尾括号，悬停查看完整内容。
- 文档、Wiki 和表格名称均使用普通灰字，不提供点击入口，不使用彩色标签、边框或名称前图标；左侧时间线动作图标保留。过程行不展示知识库列表或知识库名称。
- 文档名保留真实后缀，超长时省略主体；悬停显示完整名称。名称按实际可访问的资料元数据解析，不能根据 ID 或标题猜测后缀。
- 再次检索、再次阅读及无匹配步骤分别保留，结束结果更新原步骤，不另加重复记录。
- 无匹配显示「无匹配」；失败、取消、超时及部分读取展示实际可确认的结果与原因。未返回或无法确认的数量不补成 0，失败不能当作无匹配。
- 结果数按实际语义取值：文档阅读使用本次已读取片段数，表格分析使用查询返回行数；不能用整份文档片段总数、原表总行数或累计工具步数替代。Wiki 命中、已读、截断和未输出的页面分别处理。
- 时间线采用紧凑排版：步骤间距 9px，动作行高 20px，结果小字 11px、行高 1.5，与动作间距 1px。详情随对话增高并滚动，不单独设置内部滚动区。

##### 3.6.4 完成检索与返回统计

知识结果确认成功、部分完成或明确无结果后，在全部过程记录末尾显示完成图标、「完成检索」标题及一行统计：

```text
完成检索
共返回 6 个文档片段、1 个 Wiki 页面、1 项计算结果
```

- 完成节点仅保留标题和统计，不再展示「已查到……」等总结、摘要或其展开／收起按钮。部分完成和异常原因可在对应步骤或活动异常提示中说明。
- 统计为不可点击的普通文字，不提供链接样式、悬停高亮、来源列表入口或弹窗。
- 每条知识活动单独统计本次调用返回且当前可访问的结果，包含没有被最终回复引用的结果；不累加过程里重复命中、重复阅读的次数。
- 文档片段按片段身份去重，同一文档的不同片段分别计数；Wiki 按知识库资源身份及页面身份去重；计算结果按计算项身份去重，不以查询返回行数作为计算项数。
- 三类数量均展示，没有返回的类别显示 0。无结果示例为「共返回 0 个文档片段、0 个 Wiki 页面、0 项计算结果」。
- 仅收到执行结束阶段但结果尚未读取时，继续显示读取结果状态，不提前生成返回数量。失败、取消和超时保留实际过程与终态，不添加成功完成节点。

##### 3.6.5 正文引用与阅读内容

- 最终回复中的引用使用带图标的浅色方框标签：文档为浅蓝色文件图标及文档名称，Wiki 为浅绿色书本图标及页面名称。名称最多显示前五个字符，超出追加省略号。
- 同一处引用多个来源时并排显示多个标签；同一处连续引用同一文档的多个片段时合并为一个标签，保留各片段的引用关系。流式输出到引用位置时，直接展示名称和对应样式。
- 引用只关联所属回答已登记的证据，不串到其他回答。只有当前可访问的来源才可展示其资料名称和内容。
- 点击具体引用后，直接打开统一预览区：文档引用展示全文并高亮当前入口关联的片段，Wiki 展示完整正文并保留 Markdown 标题、段落、列表和表格，计算引用展示该计算摘要。
- 文档预览展示全文；合并引用仅高亮当前入口中属于所点击文档的片段，不高亮其他引用位置或其他文档的内容。
- 同一文档的不同片段及跨回合引用共用一个文件标签。点击另一处引用时在同一全文中切换高亮并定位到对应片段；普通标签切换保留当前阅读位置。同名不同文档按稳定标识区分，不能按名称误合并。
- 当前方案不提供「本轮引用知识」来源浮窗、悬停内容浮窗、知识卡片列表或引用内容弹窗。预览区直接显示正文，不经过「查看」中间入口，也不增加知识引用下载按钮。
- 预览区宽度、标签栏、文件切换及关闭行为沿用 3.5 和第四章。打开、切换和关闭知识预览时，保留任务列表及工作空间当前显隐状态；资料失去权限或正文缺失时显示明确提示。

##### 3.6.6 异常、历史恢复与接入约束

- 部分完成保留已获得的过程与结果数量，并说明可确认的截断或遗漏原因；无结果不能伪造引用或结果数量。
- 失败、取消和超时保留此前已完成的步骤，尚未结束的步骤显示实际中断或失败结果。整轮对话状态与知识调用状态分别收口。
- 历史恢复保留每次调用的过程和结果，重连或重放按步骤身份及序号去重，旧事件不得回退已完成状态。切换任务后不得带入上一任务的知识活动或预览内容。
- 过程字段需包含稳定步骤身份、工具名、开始顺序、更新序号、状态、实际查询／阅读对象及结果计数；前端据此映射动作、args 和结果小字。仅有阶段、累计计数或最终证据时，不能推测完整过程。
- 当前原型使用本地过程及证据样例验证展示；正式接入时需由后端保存并提供可在运行中读取、可在历史恢复的过程明细。知识结果、引用内容及资料元数据均按当前访问权限读取。

### 4. 预览区

#### 4.1 位置、宽度与文件来源

- 新增统一文件预览区，位于对话区右侧、工作空间左侧。
- 知识引用、对话生成文件、工作空间文件统一接入此区域；支持不在工作空间中的临时文件，打开预览不自动将其保存到工作空间。
- 默认宽度为 **480px**；支持拖动左边缘拉宽、收窄，手动调整后在本页、可用空间内保留所选宽度。默认及手动宽度均遵守 3.1 的边界规则。
- 从对话区打开知识引用或文件卡片时，工作空间已展开则保持展开，已隐藏则保持隐藏；文件入口规则如下：

  | 文件打开入口                                               | 工作空间状态                       |
  | ---------------------------------------------------------- | ---------------------------------- |
  | 知识引用（文档片段／Wiki 正文）                            | 保持当前显隐状态                   |
  | 对话区文件卡片，包括生成文件、临时文件、附件及工作空间引用 | 保持当前显隐状态                   |
  | 工作空间文件树                                             | 保持展开，预览区显示在工作空间左侧 |

#### 4.2 文件标签栏

- 文件标签悬停提示统一分两行：第一行显示来源类型（工作空间文件、知识库文档、知识库 Wiki 或临时文件），第二行仅显示完整名称及后缀，不显示目录路径。沿用路径浮窗的字号、留白、圆角和轻阴影；宽度随名称展开，只有超过窗口可用宽度时才换行，不省略。当前与未选中的标签均适用，关闭按钮保留独立的关闭提示。

- 顶部为 **40px** 高的文件标签栏。
- 支持多个文件标签并存、切换查看。重复打开同一文件时激活已有标签；同名不同文件、不同产物版本分别展示，不能仅按文件名合并。
- 标签栏为白色背景，标签高度为 **26px**；选中标签为 **`#E5E7EB`** 灰色圆角矩形，悬停为更浅的 **`#F3F4F6`** 灰色，未选中标签融入白色背景。
- 标签过多时隐藏横向滚动条，仅在对应方向仍有标签时显示左右渐隐箭头，沿用输入区引用资料的灰色箭头及渐隐效果。箭头用于浏览标签，点击标签才切换文件；选中后保证该标签及关闭按钮完整可见。
- 新增、关闭标签及调整预览区宽度后，同步更新标签滚动位置和箭头显隐。

#### 4.3 关闭与侧栏状态保持

- 单个标签使用普通 `×` 关闭。关闭当前标签后激活相邻标签；关闭非当前标签不影响正在阅读的文件。
- 整个预览区使用独立的「圆圈 ×」关闭图标，与标签关闭图标区分，悬停提示为 **「关闭预览区」**。
- 整体关闭按钮固定在标签栏最右侧，位于标签滚动区域之外，始终可见；与标签带之间的竖向分隔线上下留白。
- 切换标签、重复打开已有文件或关闭任意标签时，任务列表和工作空间均保持当前显隐状态。
- 关闭整个预览区或最后一个标签时，仅清空文件标签和预览内容，任务列表与工作空间保持当前显隐状态及已调整宽度；释放的空间交给对话区。关闭操作始终可执行。
- 切换到其他任务或新建任务时，关闭原预览区，关闭动作不改变侧栏显隐，后续目录定位遵循任务切换规则；点击当前任务保留预览区。

#### 4.4 正文内容

- 知识引用直接展示文档全文及引用高亮，或 Wiki 正文，不展示引用知识卡片列表；具体规则见 3.5。
- 正文背景为**纯白色 `#FFFFFF`**，标签栏下增加路径与操作栏，其下展示文件正文。文件名显示在标签上，下载操作继续保留在文件原入口。
- 预览区正文默认字号为 **14px**，包括 Markdown 正文和普通文本；行内代码、代码块及源码文件使用 **12px**，与对话区保持一致。
- 报告、摘要等原型文件使用完整、正常的业务样例数据。
- 文件正文与标签栏分别滚动，切换文件后保留各自阅读位置。
- 历史产物按原回合版本预览；加载失败时可在标签内重试，格式不支持时提示从原入口下载。

#### 4.5 路径与操作栏

- 文件标签栏与正文之间增加白底路径与操作栏，固定高度 36px，低于上方 40px 文件标签栏。路径使用浅灰底、细边框的椭圆胶囊包裹，宽度随路径文字长度变化，短路径不拉伸，最长不超过左侧可用宽度；开头图标和右侧操作按钮的位置保持固定，分别区分工作空间文档、知识库文档和知识库 Wiki，并与对应文件标签共用同一图标。
- 工作空间文件显示 `workspace/目录/.../文件名称.后缀`；知识库文档显示 `知识库名称/子目录/.../文档名称.后缀`；Wiki 显示 `知识库名称/一级索引/二级索引/.../wiki 名称`。临时文件使用 `临时文件/名称`，不伪造工作空间归属。
- 路径始终单行，不换行。空间不足时将前面的目录替换为「…/」，优先保留末级文件名及后缀；文件名本身仍过长时省略其开头并保留末尾及后缀。悬停展示完整路径，调整宽度后重新计算。路径悬停提示分两行：上方按来源独立显示「工作空间文件」「知识库文档」或「知识库 Wiki」，下方显示完整路径；使用白底、浅灰细边框、10px 圆角及轻阴影，上行 11px 灰色半粗字，下行 12px 深灰正文，间距 4px、内边距 10px 12px。工作空间文件、知识库文档和知识库 Wiki 共用同一宽度规则：浮窗随完整路径展开，不设固定像素上限；路径优先单行，只有超出视口可用宽度时才换行，不省略。浮窗与窗口左右边缘至少留 8px；栏内路径继续单行省略。
- 右侧固定预留两个 28px 图标按钮的位置及 4px 间隔（共 60px），路径省略不侵占按钮区域。只有一个操作时靠右显示，按钮提供完整悬停提示和辅助名称。

| 来源         | 操作                               |
| ------------ | ---------------------------------- |
| 工作空间文件 | 新开网页标签页查看                 |
| 知识库文档   | 定位到引用片段、新开网页标签页查看 |
| Wiki         | 在图谱中查看                       |

- 知识库文档展示全文，引用片段以浅黄色高亮；点击引用或定位按钮跳到当前引用位置，同一文档不同引用继续复用标签，普通切换标签保留阅读位置。未取得完整文档时明确提示，仅展示已有片段；无权限时不显示路径及操作。
- 新网页独立展示打开时的文件版本，关闭原预览区后仍可阅读和刷新；Wiki 图谱入口在独立网页展示索引关系并定位当前 Wiki。当前均为浏览器本地演示，未接入真实知识中心。

### 5. 工作空间

#### 5.1 布局与工具按钮

- 工作空间位于页面最右侧，默认收起，打开时默认宽度为 **200px**，通过顶部 Banner 的独立按钮控制显示／隐藏。
- 标题栏及文件树所在侧栏统一使用极浅灰色 **`#FAFAFA`**；选中的预览文件使用与任务列表一致的 **`#E8F0FF`** 浅蓝提示。
- 支持拖动左边缘调整宽度，隐藏后再次展开，在可用空间内保留本页调整的宽度，边界规则见 3.1。
- 上传文件、新建文件夹按钮采用统一的线条图标、尺寸、圆角及悬停反馈，并提供操作提示。

#### 5.2 与预览标签联动

- 选中某个预览标签时，若该文件属于当前专家工作空间且工作空间已展开，自动展开该文件全部父级目录，在文件树内滚动定位并高亮文件。
- 工作空间隐藏时，切换预览标签不强制展开；再次手动展开时，定位当前预览文件。
- 关闭当前标签后，若新激活的相邻标签属于工作空间文件，同样执行定位；关闭非当前标签不改变当前浏览目录。
- 按文件标识关联，避免同名知识文件或临时产物误选工作空间文件。
- 定位文件不改变当前任务的工作目录，不影响对话阅读位置，保留其他目录的展开状态。
