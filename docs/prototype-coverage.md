# 原型覆盖与演示边界

规则核对顺序：`数字员工/docs/design/1023/experts_prd.md`、其引用的 `prd.md`，再到未被修改的 MVP PRD，最后用当前原型补足已明确的页面细节。旧文档中独立定时任务和根级事件绑定方案已取消；本工程没有对应入口。

## 已实现的本地演示路径

- **专家与模板**：我的专家搜索，创建、编辑和删除，从专家发起对话；单页创建弹窗支持从零开始、复制专家模板、复制已有专家、头像选择与默认模型；模板浏览、从模板创建，以及把专家发布到演示模板库。
- **专家管理**：岗位说明三段编辑与统一保存；预置问题开关、排序、去重与 20 条／200 字限制；专家工作空间；记忆开关与条目；技能来源筛选、主动学习开关；工具、MCP 和三种消息渠道的本地配置。
- **人工对话**：对话创建、重命名、删除、软归档与恢复；会话切换、工作目录、预置问题填入、问题导航、模拟流式回复、工具步骤、澄清与审批卡片。模拟流可停止，离开页面也会停止。
- **消息渠道任务**：按聊天聚合的群聊卡片、搜索及渠道／聊天类型筛选、成员与历史段的只读详情。卡片与人工会话不是同一对象。
- **自主任务**：事件动作列表、启停、Timer/WebHook 示例、手动模拟触发和运行记录。此处不建立独立定时任务。
- **项目**：项目列表按原型展示图标、状态、简介、看板进度、专家头像和更新时间；新建项目为“项目信息 → 项目成员”两步弹窗，支持预设图标或本地图片、搜索并勾选专家；编辑项目可修改图标与资料，删除使用确认弹窗。项目详情已同步紧凑顶栏、看板／动态／工作空间三 Tab、四列看板与右侧成员栏；发起目标、发起记录、新建／编辑任务、任务详情三 Tab、添加成员、文件夹新建／重命名、文件预览和转交任务使用原型对应的弹窗结构。本地模拟任务状态、评论、目标拆解与文件操作。看板卡归档不影响人工会话。
- **多项目样例**：固定提供工厂质量提升、供应链数字化规划、园区能耗优化、关键设备预防性维护 4 个项目；共 32 项任务、8 条目标记录，并提供项目动态、可预览的 Markdown／CSV 文件及 3 位新增专家。旧浏览器状态按固定 ID 一次性增量补齐。
- **工作空间**：专家根路径演示设置、文件夹、上传、预览、下载、重命名、多选删除及保持目录结构的 ZIP 下载。上传内容保存在浏览器 IndexedDB。

## 演示约束

- 所有对象只存在于当前浏览器。渠道“连接”“主动沟通”、MCP“测通”、事件触发、目标拆解和对话回复均为确定的本地模拟，不代表真实服务可用。
- 消息渠道详情为只读示例；不会从 Web 端向真实企业微信、钉钉或飞书发送消息。自主任务不连接事件中心或 Hermes。
- 项目文件和专家文件由不同的本地集合管理。上传文件并不会进入服务器文件系统；清除浏览器站点数据后不能恢复。
- 本工程是主页面和关键交互的演示实现，不包含真实模型推理、权限校验、租户数据隔离、后台任务调度或 PRD 中尚未拍板的产品规则。
